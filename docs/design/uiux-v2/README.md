# Cute Pet Companion UI/UX JSON v2.0

This package is a structured UI/UX reference for implementation, aligned with the proposed pastel/glass Control Center concept.

## Files
- `uiux_spec.json`: consolidated specification.
- `design_tokens.json`: color, typography, spacing, effects and layout tokens.
- `navigation.json`: sidebar and footer structure.
- `screen_specs.json`: screen layouts and section requirements.
- `component_specs.json`: notification card, pet attachment, mode tile, pet card and app chips.
- `behavior_rules.json`: policy and behavior requirements.
- `accessibility.json`: accessibility targets.
- `IMPLEMENTATION_GUIDE.md`: practical integration order and guardrails.

Treat this as a design contract, not a mandate to replace existing architecture. Audit the current code and reuse existing state, controllers, integrations and components.
